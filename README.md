# 通用短剧创作大师

这是一个给 Codex 使用的通用视频创作 Skill。它可以处理短剧、广告、MV、宣传片、预告片、纪录片、教程、竖屏短视频和世界观展示片。

v2.0 不再一次写完整部影片的全部视频提示词。它先制作 Clip 01，等你提供真实生成结果后，检查画面实际停在哪里，再从那个真实结尾写 Clip 02。

## 为什么这样做

视频模型不一定严格执行纸面计划。人物可能提前完成动作，机位可能偏移，表情和站位也可能变化。如果先把后面所有提示词写死，下一段很容易出现动作重复、人物瞬移、光线跳变或镜头接不上。

新流程把真实成片放在最高优先级：

```text
写当前 Clip
-> 生成当前 Clip
-> 检查真实结尾
-> 锁定人物、动作、机位、光线和声音状态
-> 从真实结尾写下一 Clip
```

## 它能做什么

- 把一句想法整理成创意简报、故事路线和完整剧本
- 为当前 Clip 设计动作、镜头、光线、对白和声音
- 输出可直接复制到视频模型的纯提示词
- 使用 `@图片1`、`@视频1`、`@音频1` 等模型可识别引用
- 检查真实视频末帧，再续写下一段
- 设计原创角色、场景、道具、怪物和交通工具
- 按需生成角色、场景或分镜图片
- 按用户提供的 Word 模板整理制作文件
- 自动拦截累计时间码、内部资产编号、文件名和解释性废话
- 在停止生图后保留已有结果并继续文本制作

## 核心规则

1. 一次只写一个可执行 Clip。
2. Clip 02 必须等待 Clip 01 的真实结果。
3. 每个 Clip 都从 `0秒` 开始计时。
4. 人物形象保持一致，动作、姿势、表情和机位按剧情变化。
5. 提示词中不出现资产编号、文件名、本地路径或制作说明。
6. 生成提示词只包含模型需要执行的内容。

## 导演四问

写每个 Clip 前，Skill 会先在内部回答：

1. 这场戏在做什么？
2. 镜头怎么把它说出来？
3. 光帮这场戏做什么？
4. 声音帮这场戏做什么？

这些分析不会污染可复制提示词。

## 最终文件

制作型项目默认分成两类文件。

### 制作文件

包含剧本、故事路线、导演卡、真实末帧记录、连续性分析、内部资产清单和质检结果。

### 纯提示词文件

只包含可以直接粘贴到图像或视频模型的提示词。不会出现：

- `资产引用`
- `REF-001`、`CHR-001` 等内部编号
- `.png`、`.mp4` 等文件名
- `prompt-only`
- “直接使用用户图”
- “上图只是……”
- 工作流解释和复制说明

## 时间规则

每段独立计时：

```text
Clip 01
0-3秒
3-8秒
8-15秒

Clip 02
0-4秒
4-10秒
10-15秒
```

Clip 02 不会写成 `15-30秒`。

## 使用方法

在需求中写：

```text
使用 $short-drama-creation-master，帮我制作一个 2 分钟奇幻战斗短片。
先写完整故事路线和剧本，但视频提示词只制作 Clip 01。
```

拿到 Clip 01 的真实视频后继续：

```text
这是 Clip 01 的真实结果。检查它实际停在哪里，再从真实结尾制作 Clip 02。
```

## 参考图片

提供图片后，提示词使用模型能识别的顺序引用：

```text
@图片1锁定队长外观，@图片2锁定场景结构，以@视频1最后一个稳定画面为动作起点。
```

内部文件名不会出现在可复制提示词中。

## Word 文档

需要 Word 时可以说：

```text
按照我提供的 Word 格式整理制作文件，并单独输出纯提示词文档。
```

Skill 会使用文档工具生成、渲染并检查 `.docx`。制作说明与模型提示词会分开，提示词区域可以直接复制。

## 工具

创建项目：

```bash
python3 scripts/init_video_project.py \
  --output ./outputs \
  --title "项目名称" \
  --type narrative-short \
  --duration 90 \
  --clip-duration 15 \
  --aspect 16:9 \
  --language zh-CN
```

检查单个提示词：

```bash
python3 scripts/lint_copy_ready_prompt.py \
  ./outputs/项目名称/03_clips/CLIP-01/prompt.txt \
  --duration 15
```

检查整个项目：

```bash
python3 scripts/validate_video_project.py ./outputs/项目名称
```

锁定上一段真实结尾后创建下一段：

```bash
python3 scripts/create_next_clip.py ./outputs/项目名称 --duration 15
```

如果上一段没有真实末帧记录，工具会拒绝创建下一段。

## 安装

把仓库放到 Codex Skills 目录：

```bash
git clone https://github.com/eventlp02-commits/storyforge-agent.git \
  ~/.codex/skills/short-drama-creation-master
```

开启一个新任务后即可使用 `$short-drama-creation-master`。
