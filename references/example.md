# Example

The following is a provider-style continuation prompt for a 15-second shot. Adapt reference syntax to the actual target model.

```text
@视频1用于继承上一段最后一个稳定画面中的人物站位、动作阶段、机位轴线和冷暖光关系；@图片1用于锁定主角的面部、发型、服装与短刀造型。

0-4秒：主角保持画面右侧半蹲姿势，右手仍撑地，先抬眼看向画面左上方；低机位近景缓慢后移，肩甲上的碎石落下，门外冷光从左侧切入，空旷大厅里只保留呼吸与远处风声。
4-9秒：主角借左腿发力站起，把短刀拉到身体右侧，动作从恢复进入戒备；镜头继续后移至中景，不跨越人物视线轴，甲片摩擦声与鞋底擦过石面的声音同步出现。
9-12秒：柱顶阴影从画面左上方掠过，主角只转肩和视线跟随，不重复起身；镜头顺着视线小幅上摇，冷光压暗面部下半部，高处传来一次短促金属碰响。
12-15秒：阴影停在柱顶边缘，主角横刀稳定重心；镜头停止移动形成清晰的上下层构图，环境声收窄到呼吸和细小碎石落地声，结尾保持双方位置、动作方向和机位侧别清楚可续接。

中文对白与口型同步，无配乐。保持人物身份、服装、武器、空间结构和屏幕方向稳定；动作连续，不重复起身，不瞬移，不突然跨轴。
```
